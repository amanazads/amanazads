# 🚀 Featured Projects

## 01 — AgentPay

### Autonomous AI Commerce Control Plane

An AI commerce authorization system designed to separate **LLM reasoning from deterministic financial execution**.

**Architecture**

```text
AI Agent
   │
   ▼
Reasoning / Discovery
   │
   ▼
Policy Engine
   │
   ▼
Risk Engine
   │
   ├───────────────┐
   ▼               ▼
Approval        Transaction
   │               │
   └───────┬───────┘
           ▼
      Audit Trail
```

### Highlights

* Deterministic policy enforcement
* 13 policy rules
* Explainable 0–100 risk scoring
* Prompt-injection protection
* Human approval workflows
* Redis-based idempotency
* Payment verification
* Immutable audit logging
* 1,000-case simulation harness

**Stack**

`React` `Node.js` `Express` `Python` `FastAPI` `PostgreSQL` `Redis`

🔗 **Repository:**
https://github.com/amanazads/AgentPay

```text

LangGraph Router
    ├── RAG Retrieval
    ├── Business Tools
    ├── General Response
    └── Human Escalation

      Grounded Response
```
